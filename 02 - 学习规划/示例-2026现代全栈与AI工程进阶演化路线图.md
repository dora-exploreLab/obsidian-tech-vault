## 🎯 二、三大攻坚战役与里程碑 (Learning Sprints)

### 战役一：智能体运行时 Harness 模式深入 (Weeks 1~4)
* **核心目标**：彻底吃透状态机、记忆环路与工具调用熔断机制。
* **研读参考**：
  - [[MCP 模型上下文协议]]
  - [[ReAct 认知循环范式]]
* **结项交付物**：独立开发一个支持标准 MCP 协议的上下文连接器。
* **验收打卡**：
  - [x] 阅读并精读 Anthropic MCP 协议规范
  - [x] 实现基于 SSE / Stdio 的双向通讯适配器
  - [ ] 编写基于 Vitest 的端到端时序回归用例

---

### 战役二：千万级数据流下的分布式幂等与一致性 (Weeks 5~8)
* **核心目标**：突破高并发写入下的排重瓶颈与数据库连接池优化。
* **研读参考**：
  - [[分布式一致性与幂等锁]]
  - 《数据密集型应用系统设计 (DDIA)》第 7、8 章
* **结项交付物**：在本地 Docker 集群完成万级 QPS 并发压测与崩溃演练报告。
* **验收打卡**：
  - [ ] 搭建 PostgreSQL 16 双节点读写分离与主从同步
  - [ ] 针对 Redis 悲观锁与 Redlock 方案进行对比基准压测
