## 🌟 Why Geek-Vault-Template?

Most developers struggle with Obsidian because an empty vault offers zero structure.  
**Geek-Vault-Template** is distilled from real-world engineering and AI research workflows:

1. **Structured 10-tier Decimal Taxonomy**:
   - Combines the clarity of **Johnny Decimal** numbering with the agility of **PARA** (Projects, Areas, Resources, Archives), preventing deep folder sprawl.
2. **12 Production-Ready Markdown Templates**:
   - Covers daily reviews, full-stack architecture designs, LLM fine-tuning logs, AI Agent architectures, paper reading notes, and agile kanbans.
3. **Autonomous Agent Ecosystem**:
   - The `05 - 收件箱/` directory structure natively pairs with [**`tech-radar-agent`**](https://github.com/dora-exploreLab/tech-radar-agent), continuously capturing trending intelligence into your second brain.

## 🗂️ Vault Directory Architecture

```text
geek-vault-template/
├── 00 - 个人说明/          # 👤 Developer technical persona & vault maintenance guide
├── 01 - 项目介绍/          # 🚀 Engineering architectures, tech specs & deliverables
├── 02 - 学习规划/          # 📚 Long-term technical roadmaps & skill mastery plans
├── 03 - 待办事项/          # 📌 GTD task pool, top priorities & agile kanban
├── 04 - 周期复盘/          # 📅 Daily work logs, weekly retrospectives & monthly OKRs
├── 05 - 收件箱/            # 📥 Autonomous tech radar captures & raw notes
├── 06 - 知识卡片/          # 🗃️ Zettelkasten atomic notes & mental models
├── 07 - 手册资料/          # 🧰 CheatSheets, API references & book deep-dives
├── 08 - 深度专题/          # 📐 Research topics, experiments & deep investigations
└── Templates/              # 🌟 12 standardized, battle-tested Markdown templates
```

## 📋 12 Standardized Markdown Templates

| Template | Use Case |
| :--- | :--- |
| **`Daily Note`** | Top 3 priorities, daily engineering flow, insights & reflections |
| **`Frontend Tech`** | Full-stack architecture, component design, state management & performance |
| **`DevOps & Tunnel`** | Reverse proxies, Cloud jumper servers, port mapping & firewall whitelist |
| **`LLM Training`** | Model fine-tuning parameters, dataset cleaning, loss tracking & eval |
| **`AI Agent`** | Planner, memory layer, tool execution, MCP schema & multi-agent topology |
| **`Paper Reading`** | Breakthrough mechanisms, algorithmic flows, experiments & takeaways |
| **`Zettel Note`** | Atomic concept note, bi-directional linking & essence extraction |
| **`Project`** | PRD goals, technical decisions, milestones & delivery review |
| **`Tech Meeting`** | Design review background, debate points, resolutions & action items |
| **`Daily Todo`** | Lightweight daily GTD checklist |
| **`Monthly Kanban`** | Monthly OKRs, stage deliverables & kanban board |
| **`Weekly Review`** | Highlights, sprint retrospective, blockers & next week agenda |

## 🚀 Quick Start (In 30 Seconds)

### Method 1: GitHub Template (Recommended)
1. Click the green button at the top: **`Use this template` ➡️ `Create a new repository`**;
2. Name your private or public vault (e.g. `my-second-brain`);
3. Open Obsidian ➡️ Click **"Open folder as vault"** ➡️ Select the cloned directory!

### Method 2: Git Clone
```bash
git clone https://github.com/dora-exploreLab/geek-vault-template.git my-vault
```

## 🔌 Recommended Obsidian Plugins

To maximize your workflow efficiency, install these popular community plugins:
* **Dataview**: Query and aggregate your notes, projects, and metadata like a SQL database;
* **Templater**: Insert templates from `Templates/` with a single shortcut;
* **Kanban**: Turn `03 - 待办事项/` into an interactive agile board;
* **Omnisearch**: Sub-second fuzzy search across your entire vault.

## 🤖 Agentic Ecosystem Integration

Pair this vault with our open-source [**`tech-radar-agent`**](https://github.com/dora-exploreLab/tech-radar-agent):
* Runs daily autonomously to capture trending GitHub repos, top ArXiv AI papers, and engineering blogs;
* Structures the intelligence and saves it directly into **`05 - 收件箱/`**, while checking off your daily todo item!
